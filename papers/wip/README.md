# GCS specialist-hybrid / JEPA paper (WIP)

**Branch:** `wip` only. **Status:** Draft v0.1, November 2, 2026.

This research paper develops a testable case for a specialized hybrid Genius Cognitive System architecture. It draws on Balestriero and LeCun, *Proving and Improving the Platonic Representation Hypothesis with JEPAs* (arXiv:2610.39302). Their alignment findings are cited as background research, **not** as proof of better GCS reasoning quality.

- `GCS-Specialist-Hybrid-JEPA-Working-Paper.tex` — editable LaTeX
- `GCS-Specialist-Hybrid-JEPA-Working-Paper.pdf` — compiled review copy

**Do not merge this draft into `main`, add it to `catalog.json`, or publish it on GitHub Pages until the code, tests, benchmarks, and proofs are complete and reviewed.**

This repository is public: the `wip` branch is available on GitHub to anyone with the link despite being absent from the site's catalog.
