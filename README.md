# Super-Genius research, articles and patents

The public GitHub Pages site for Kenneth Hurley's technical writing.

**Website:** https://super-genius.github.io/

## Adding an article

Edit `catalog.json` and add a new entry with `title`, `type`, `area`, `url`, and `desc`. Optional: `source`.

For PDF papers, add the original PDF under `papers/` or `patents/` and set the relative `url`. Do not publish confidential or third-party material without permission.

The site is static (HTML/CSS/JavaScript) and loads the catalog client-side. It requires no build process.

## Notes

Some documents use an arXiv-style format but were not submitted to arXiv. Design papers should not be presented as experimental proof. Older writing appears for historical reference. The original `Eigenvectors/` directory is preserved.
